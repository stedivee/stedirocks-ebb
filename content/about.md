# Tietoja uteliaille

Olen entinen web-asiantuntija/kouluttaja, joka opettelee uusia teknologioita ja työkaluja, pitkän tauon jälkeen. Niitä onkin paljon, sillä aikoinaan kun lopetin palkkatyöni siirryttyäni eläkkeelle, lopetin myös lähes kaiken mahdollisen IT-homman. Tai siis lopetin aktiivisen oman taitojeni ylläpidon ja uusiin asioihin tutustumisen. WordPress-juttuja tulee vielä tehtyä pikkuisen, mutta muuten uuden oppiminen loppui kuin seinään. Uusien asioiden opettelua ja kehityksen kelkassa pysymistä se kouluttajan työ oli paljonkin. Se oli mukavaa, pidin uuden oppimisesta. Mutta oli kivaa vapautta aivot vaiheeksi jatkuvasta tietotekniikan uutuuksien oppimisesta harrastuksiin, noh, toki uutta siellä harrastuksissakin tuli opittua. Tilalle minulla tuli siis kaikki harrastukset, joiden parissa se aika onkin hyvin sujunut. Nyt 70+ ikäisenä otin ihan huvin vuoksi itselleni haasteen, opin taas uusia juttuja, niitähän riittääkin  
Vieläkö opin?

 - Eleventy
 - Git (Github ja Codeberg)
 - Jamstack
 - VS Code ja VSCodium
 - Node.js
 - Uudet jutut HTML, CSS ja JavaScript-tekniikoissa, (kyllä siitä on jo useampi vuosi kun viimeksi näitä koulutin)
 - Markdown
 - Front Matter
 - statichost-palveluntarjoajan palvelut

Ja paljon muuta, mutta tässä on vain muutamia esimerkkejä itselleni uusista asioista.

Blogi minulla on edelleen WordPressissä [teuvovaisanen.fi](https://teuvovaisanen.fi), mutta jos opin tämän uuden tavan tehdä sivustoja, niin melko varmaan siirryn Eleventyllä rakennettuihin staattisiin webbisivuihin.
